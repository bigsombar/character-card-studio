Character Card Studio — V3 character card and lorebook editor

Character Card Studio is a free, local-first online editor for Character Card V3 (CCv3) cards and lorebooks used with SillyTavern and compatible AI roleplay frontends. Create, edit, validate and export character cards without installing desktop software.

What you can edit

  • Character name, description, personality, scenario and first message.
  • Alternate greetings, group-only greetings, example messages and creator notes.
  • System prompts, post-history instructions, tags, source links and multilingual creator notes.
  • Full CCv3 lorebooks: entries, keys, secondary keys, regex triggers, position, priority, insertion order, per-entry extensions and character book settings.
  • Embedded images, audio and video, including linked media downloads and image compression.

Supported formats

  • CHARX archives with card.json and embedded media.
  • V3 JSON cards with optional inline data URLs.
  • V3 PNG cards with an embedded ccv3 chunk.
  • V2 PNG and V2 JSON cards, upcast to V3 on import. V2 export is not supported.

Local-first and private

Cards and media are stored in your browser using IndexedDB. There is no account, backend or telemetry. Export a backup before clearing site data.
